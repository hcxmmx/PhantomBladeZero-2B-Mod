# 0.2.52 版本说明

移除左上角常驻调试提示，以及 F8/F9 调参面板入口。玩家包不再包含两份面板资源，不会切换鼠标或输入模式。
默认步态、待机、裙骨及胸部参数与0.2.51一致，调参读取改为固定值；裙摆避让和胸部起伏计算保留。模型尺寸仍为110%。
本次没有新增语音；语音实验包独立于此模型发布。

0.2.51已有作者逐轮实机试玩的模型、贴图、基本动作及受击基础。0.2.52完成必要构建和资源加载检查，清理后的实机外观尚待反馈。

已知限制：部分裙腰/大腿位置仍有小面积穿模；某些武器握持有轻微偏差。没有独立头发物理、完整表情或逐段过场适配，少年魂及其他服装未逐一验证。
裙摆采用骨骼方案，未使用此前Chaos Cloth实验。

工程保留调试工具、面板及development/tuning-0.2.51原动画蓝图，玩家无需操作。
