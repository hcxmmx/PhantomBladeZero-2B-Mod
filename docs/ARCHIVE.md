# 存档范围

本仓库保留当前选用的源码、蓝图、模型、材质占位与贴图，以及关键处理脚本。Blender和FBX来自0.2.48，运行图最终为0.2.51，两者构成发布版本。

没有包含：原游戏主角网格/动画、游戏安装文件、其他作者的只狼Mod包、第三方工具二进制或源码副本、UE编译缓存、临时分析数据、资源密钥、日志、崩溃转储、个人录像。

UE资源可能仍保留导入时的历史文件位置元数据；重新导入时请手动选择本仓库model目录中的文件。常规浏览蓝图不需要原导入路径。

工程保留源码是为了存档与交流。第三方模型、贴图和游戏骨架数据的来源见Credits，未额外为这些素材授予开源许可。没有为整个混合素材工程套用MIT等统一许可证；自写代码如后续确定许可证，再单独明确范围。

本地整理版本未执行一次全新环境重建；唯一面向玩家的发布包使用已部署0.2.51的资源三件套。
