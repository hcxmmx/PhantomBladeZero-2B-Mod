# 安装与卸载

适用对象：PC Steam 版《影之刃零》，成年魂的默认外观。本机制作、测试基于 Steam build 26266538；其他游戏更新、服装、少年魂及过场兼容性未逐一验证。

1. 退出游戏。
2. 如果装过其他魂的角色替换，请先将其文件移出 `~mods`；只狼示例的文件名为 `zzz_RyuSoul_P.*`。旧版本 Mod 同样先备份。
3. 解压玩家安装包，将其中的 `ProjectPBZ` 文件夹合并到游戏根目录（即原本就包含 `ProjectPBZ` 文件夹的位置）。
4. 最终三个文件应位于 `ProjectPBZ/Content/Paks/~mods/`：
   - `zzz_Hcxmmx2B_Retarget_P.pak`
   - `zzz_Hcxmmx2B_Retarget_P.utoc`
   - `zzz_Hcxmmx2B_Retarget_P.ucas`
5. 正常启动游戏，继续成年魂存档。

本 Mod 本身不需要安装或开启 UE4SS，不需要 Mod Manager。不要因为本 Mod 擅自删除其他 Mod 依赖的加载器。

**F8**：步态、待机腿部调节。**F9**：裙骨与胸部调节，胸部控制在面板下方，向下滚动可见。再按同一个键关闭。一次打开一个面板；参数在本次会话内生效，重启恢复默认。左上角的快捷键提示属于当前版本。

默认值：移动足部外转17°、单侧脚位偏移3cm、膝盖引导向内6cm；移动/待机过渡0.35秒。待机脚位偏移每侧-4.08cm、膝盖向内3.99cm，待机足部方向修正关闭。裙骨余摆0.6、回弹145。胸部强度1.2、回弹160。

卸载：退出游戏，只移走上面这三个文件。回退：退出游戏后将你备份的旧三件套放回同一位置。

没有显示时，先核对目录、三件文件是否齐全、是否仍有另一个角色替换。换武器仍有小幅握持偏差属于已知问题，不代表安装失败。
